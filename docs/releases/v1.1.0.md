# Emlékőr 1.1.0

Magyar, offline emléknapló Android 8.0 vagy újabb rendszerre.

- Saját SVG-illusztrációk, részletesen növekvő emlékkert és négy választható kerthangulat.
- Nyolc emlékösvény, hat album és tizenkét képes jelvény.
- Háromlépéses naplóírás, piszkozat, keresés, kedvencek és nagyobb betűk.
- Titkosított Android-adattár és jelszavas `.emlekor` mentés; a régi mentésformátum támogatása megmaradt.
- Nincs fiók, reklám, analitika vagy internetes engedély.

## Letöltés

Az `Emlekor-1.1.0.apk` a telepítő. Az `Emlekor-1.1.0-forraskod.zip` az eredetileg átadott forráscsomag; a GitHub automatikus Source code archívuma a kiadási tag teljes repóállapotát tartalmazza. Az eredeti APK és ZIP SHA-256 összege a `SHA256SUMS` mellékletben található.

Frissítés előtt készíts jelszavas mentést. A régi alkalmazást ne távolítsd el; meglévő telepítés frissítéséhez egyező aláírás szükséges.

Fizikai Android-telefonos teszt még nem történt. A böngészős és Java-tesztek nem helyettesítik a natív Keystore, dokumentumválasztó és megosztás eszközpróbáját. Részletek a repó VALIDATION.md fájljában.
